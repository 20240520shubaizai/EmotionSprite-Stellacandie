# Golden Set v2 变更记录

- 版本：2.0.0；冻结日期：2026-08-22。
- 用例从20组扩展为25组，并加入人格、幻觉、提醒、权限、隐私、梦境边界和健康安全分类。
- 删除依赖`model_behavior`的伪故障用例；模型故障改由传输层故障注入测试覆盖。
- 每个用例要求经正式任务API执行，运行3轮并保留请求ID、Trace ID、均值、方差和失败样本。
- 工具成功不再以返回`success`为准，必须同时验证`executed=true`以及记录ID、文件结果或外部响应摘要。
- LLM-as-a-Judge不参与事实、权限、提醒和副作用判定，只允许作为人格与表达的辅助评分。
