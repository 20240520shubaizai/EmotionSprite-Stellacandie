# Python Agent Runtime

Agent Runtime 使用 FastAPI 提供本机 HTTP/SSE 接口，Pydantic 约束请求和返回结构，LangGraph 表达路由、检索、工具和模型节点。

一次典型请求经过：输入标准化 → 风险与任务分类 → 记忆检索 → 模型或确定性处理 → 工具审批/执行 → 结构化验证 → Trace 脱敏 → 返回 UI。

## RAG

检索同时使用关键词和语义召回，再以 RRF 融合。候选文档带来源、事实类型、置信度和生命周期。SQLite 是事实源，向量索引损坏时可重建。

## 工具

工具由注册表描述名称、输入 Schema、风险等级和幂等性。读取型低风险工具可直接执行；删除、文件处理等高风险操作要求精确确认。结果只有在真实提交后才能写成成功。

## 模型适配

文本模型使用 OpenAI 兼容协议，视觉模型通过 SiliconFlow 调用 Qwen3-VL。适配层处理超时、HTTP 错误、结构化 JSON、秘密回显防护和确定性回退。

## 可观测性

Trace 默认记录阶段、耗时、模型和错误分类，不记录 API Key、秘密正文或完整聊天内容。日志有数量和天数上限。
