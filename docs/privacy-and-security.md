# 数据、同步与隐私

## 默认本地

用户聊天、记忆、提醒、日记和状态默认只写入 `%APPDATA%\EmotionSprite\Stellacandie`。Agent 的同步 SQLite 也位于用户数据目录，不会写入安装目录或源码目录。

## 凭据

API Key 使用 Windows Credential Manager 保存。导出数据不包含凭据；彻底删除可以显式删除凭据。普通日志、数据库和同步载荷不得记录 Key。

## 同步

同步要求 HTTPS 地址和访问令牌，并按实体类型单独授权。秘密、仅本地记忆、聊天正文、图片及本地路径不在允许类型中。MySQL 只是可选远端副本，不替换本地 SQLite。

## 日志

服务日志默认不写聊天正文。Trace 只保留脱敏元数据，并受保留时间和数量限制。“秘密记忆”不能进入普通调试窗口。

## 用户权利

用户可以查看和删除记忆、导出数据、默认保留卸载或在精确确认后彻底删除。任何文件零食删除必须先获得针对具体文件的授权。
