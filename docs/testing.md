# 测试与验收

## 自动化层

- Python pytest：Agent Graph、结构化 Schema、模型回退、工具权限、同步和数据生命周期；
- Qt/C++ CTest：Agent 合同、客户端、Golden Set、Repository/迁移和认知路由；
- 发布烟测：标准安装器全新安装、升级、Agent 启动、安装目录清洁、卸载和数据保留。

当前基线为 Python 66 项通过、Qt/C++ 5 组通过。

## Windows 黑盒轮次

- R1：发现快捷方式权限失败错误地导致整次安装失败；
- R2：确认安装器降级修复，同时发现多实例数据丢失、删除记忆仍召回、提醒串线和运行中半安装；
- R3：进程、文件、数据库和 CLI 项由独立 Windows 机器验证，GUI/AI 项由项目所有者人工补测；结论为内部候选版有条件通过；
- R4：Inno Setup 安装器完成 0.8.0→0.9.0-rc.1 自动升级烟测。

“通过”按证据来源区分为自动化、独立黑盒和人工交互，不把环境阻塞写成产品通过。真实 HTTPS/MySQL 同步、代码签名、Defender 完整扫描和更多跨版本环境仍属于公开发布前的增强项。

原始数据库、聊天、设备信息和大体积证据包不进入公开仓库，仅发布脱敏后的结论。
