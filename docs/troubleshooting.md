# 故障排查

## 提示已有实例运行

检查系统托盘并退出已有桌宠。若异常退出后仍提示，确认任务管理器中没有 `EmotionSprite.exe` 或 `agent-core.exe`，然后重试。

## Agent 离线

先检查模型地址、模型名和凭据，再确认网络。安装目录中的 `Repair-Agent.ps1` 可从随包备份恢复 Agent Runtime。不要从不明来源替换运行文件。

## 安装或升级被阻止

安装器在程序运行时会在修改文件前停止。请从托盘退出后重试。标准安装器会更新同一产品的开始菜单和桌面快捷方式。

## AI 不回复或凭据错误

在设置中重新测试连接。错误 Key 不需要重装；保存正确凭据后即可恢复。请确认账户余额、模型名称和服务地址。

## 同步地址填什么

只有自行部署独立 HTTPS 同步服务后才填写服务地址和令牌。`https://sync.example.com` 是示例，不能工作。不了解该功能时保持同步关闭。

## 数据位置

主数据库在 `%APPDATA%\EmotionSprite\Stellacandie`。不要在程序运行时直接编辑数据库。排查时先退出程序，再复制数据库进行只读检查。
