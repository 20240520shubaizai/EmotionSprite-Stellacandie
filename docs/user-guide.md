# Stellacandie 用户使用说明

## 1. 安装与首次启动

从 GitHub Releases 下载 `Stellacandie-0.9.0-rc.1-Windows-x64-Setup.exe`，并用 `SHA256SUMS.txt` 校验完整性。双击安装器后可选择是否创建桌面快捷方式；程序默认安装在 `%LOCALAPPDATA%\Programs\Stellacandie`，不需要管理员权限。

首次启动会在 `%APPDATA%\EmotionSprite\Stellacandie` 建立本地 SQLite 数据。安装器不包含用户数据、聊天记录或 API Key。当前安装器没有代码签名，Windows 可能显示“未知发布者”。

## 2. 配置 AI

在聊天窗口打开“设置”：

1. 在“聊天与梦境”中填写兼容地址、模型名和 DeepSeek API Key；
2. 在“视觉识图”中配置 SiliconFlow 地址、`Qwen/Qwen3-VL-8B-Instruct` 和视觉 Key；
3. 保存并测试连接。

API Key 只写入 Windows Credential Manager。界面不会把 Key 写回聊天数据库或普通日志。没有有效凭据时，程序会进入离线/降级状态，不能保证生成真实 AI 内容。

## 3. 聊天、状态与桌宠

在聊天框输入消息并发送。每次请求都会注入当前本地时间；状态分析逻辑会根据语义、交互成本和上下文更新心情、精力、亲密度等数值。普通中性聊天通常只产生较小的精力消耗。

桌宠支持透明窗口、桌面巡游、待机动作、点击反馈和系统托盘。关闭功能窗口不会删除数据；要完全退出主进程，请从系统托盘选择退出。

## 4. 长期记忆与提醒

明确表达“请记住”或稳定事实时，系统会建立候选记忆并评估重要度、置信度和生命周期。用户可在长期记忆界面查看、修改、删除或恢复记录。删除后的内容会从活跃查询和 RAG 中失效。

提醒支持明确日期时间和“两分钟后”“两小时后”等相对时间。两条完整提醒会分别创建，不会把新提醒误当成旧提醒的补充。会议类事件完成后会归档，后续关心默认限制次数，避免每天重复追问。

## 5. 图片与总结

聊天主界面可发送图片，由视觉模型描述主要内容。图片原文件及本地路径不属于默认同步范围。

总结魔法支持粘贴或选择文章，选择模式并填写自定义要求，例如“严格总结为 3 点，并单独列出风险”。历史结果可保存和重新生成。

## 6. 日记、梦境和零食

- 反向日记：精灵以自己的视角记录当天经历，支持手动生成、历史翻页、贴纸避让和满足条件后的自动补写；
- 梦境星星纸：梦境先独立保存，再折成星星纸；用户打开星星纸不会自动变成精灵已知事件；
- 文件零食：只使用无价值测试文件或确认不再需要的文件。涉及删除时必须先获得明确授权；支持批量融合、隐藏款和饱食反馈；
- 晨间棒棒糖：在设定时间窗口随机赠送，可能受天气、纪念日和限定口味影响。

## 7. 本地数据、同步与隐私

SQLite 始终是本地事实源。同步总开关和各数据类型默认关闭。若自行部署 HTTPS 同步服务，可分别启用应用设置、精灵状态、普通记忆和提醒；秘密记忆、本地路径、聊天正文和图片不会因为打开总开关而自动上传。

“同步服务地址”不能填写示例地址，必须使用真实 HTTPS 服务和该服务签发的令牌。不了解服务器部署时请保持关闭。

## 8. 导出、升级与卸载

正式安装器能够识别同一产品的旧版本并覆盖升级。升级前先从托盘退出程序，用户数据默认保留。

Windows“已安装的应用”中可以卸载 Stellacandie。默认卸载只移除程序文件，保留 `%APPDATA%\EmotionSprite\Stellacandie`。数据导出会生成包含数据库和结构化 JSON 的 ZIP，但不会导出凭据。彻底删除需要精确确认，会同时清理本地数据和凭据，无法撤销。

## 9. 文件校验

```powershell
Get-FileHash .\Stellacandie-0.9.0-rc.1-Windows-x64-Setup.exe -Algorithm SHA256
```

输出必须与 Release 中的 `SHA256SUMS.txt` 一致。若不一致，不要运行安装器。
