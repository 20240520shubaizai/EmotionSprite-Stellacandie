# Stellacandie Room

Cocos Creator 3.8.8 互动房间原型。Qt/C++仍负责AI、数据库和规则；本项目只负责动画、场景和互动表现。

## 当前完成

- 导入现有12类状态图与逐帧动作素材。
- 混合待机控制器：呼吸、眨眼、耳动、观察、伸懒腰。
- 状态决策：低健康休息、低精力睡觉、总结时看书、低饱食度等待零食、开心时漫步。
- 点击摸头反馈与互动事件回传。
- JSON协议和浏览器预览降级存储。
- 程序化治愈房间原型：小床、窗边、零食角。

## 首次打开

1. 用 Cocos Creator 3.8.8 导入此目录。
2. 新建2D场景并创建 Canvas。
3. 在 Canvas 下创建空节点 `RoomRoot`。
4. 将 `RoomBootstrap.ts` 挂到 `RoomRoot`。
5. 保存为 `assets/scenes/main.scene` 并设为启动场景。

之后房间、精灵、状态桥接和随机待机动作均由 `RoomBootstrap` 自动建立。

## 动画策略

- 高频状态：Cocos Tween与分层细节组成自然循环。
- 明确动作：继续使用现有逐帧素材，后续制作吃、睡、伸懒腰和扑玩具AnimationClip。
- 现有状态图：作为表情关键帧与低成本兼容资源，不直接废弃。
- 特效：后续使用ParticleSystem2D表现星光、感冒和糖果。
